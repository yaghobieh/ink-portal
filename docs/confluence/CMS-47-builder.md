# CMS-47 — bifDynamic rich visual builder

Three-panel canvas in Ink portal Builder:

- Layout group: section, column, Flex, Grid, masonry, Ink, form, two/three column presets
- Widgets group: Bear catalog
- Structure tree for nested blocks
- Inspector Content (label/HTML) and Style (padding, background, color)
- Desktop / tablet / mobile stage + preview (chrome hidden)
- Persist `payload.canvas` + localStorage
